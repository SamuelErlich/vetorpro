Crie um sistema web completo em Node.js com Express, SQLite e autenticação por sessão. O sistema terá dois painéis: painel do cliente e painel admin. O objetivo é fornecer acesso a dados de credenciais mensais somente para clientes com pagamento ativo e integrar cobrança via PIX PushinPay com webhook. Requisitos detalhados: Arquitetura geral: Use Node.js + Express. Use SQLite como banco de dados local. Use EJS como template engine para as páginas. Use bcrypt para senhas. Use express-session para autenticação. Estrutura de pastas: /src /src/server.js /src/routes /src/controllers /src/models /src/views /src/public Banco de dados SQLite: Criar tabelas: users (id, name, email, password_hash, status [ATIVO, PENDENTE, INATIVO], ultimo_pagamento, vencimento, plano). payments (id, user_id, valor, txid, status [pending, paid], created_at). credentials (id, email_cred, senha_cred, valid_from, valid_to). notifications (id, user_id, message, created_at). Rotas do painel do cliente: GET /login exibe login. POST /login autentica usuário. GET /dashboard protegido. No dashboard mostrar: status do usuário, credenciais do mês (apenas se status=ATIVO), botão "Entrar agora" que abre https://vectorizer.ai/login
 com email e senha preenchidos via querystring, calendário com histórico de pagamentos, botão "Pagar via PIX". GET /pay inicia geração de PIX via API PushinPay. GET /logout encerra sessão. Rotas de pagamento PushinPay: POST /webhook receber notificações. Quando receber status pago, atualizar: payments.status="paid", users.status="ATIVO", users.ultimo_pagamento=data atual. Atualizar dashboard automaticamente. Rotas admin: GET /admin/login login admin. GET /admin painel principal com lista de usuários. POST /admin/users criar ou editar usuários. GET /admin/credentials mostrar credenciais atuais. POST /admin/credentials cadastrar credenciais do mês. GET /admin/payments listar pagamentos. GET /admin/notifications enviar notificações manuais para um usuário. Lógica de bloqueio automático: Todo dia 6, verificar quem não pagou no mês atual e definir users.status="PENDENTE". Calendário do cliente: Criar componente que mostra 12 meses, com cor verde se pagou, amarelo se pendente e vermelho se atrasado. Botão de suporte: No painel do cliente incluir link "Suporte": https://wa.me/SEUNUMERO
. Integração com PushinPay: Criar função express para gerar PIX: endpoint: POST https://api.pushinpay.com.br/pix
. Parâmetros básicos: valor, chave_pix, txid. Retornar QR Code e copia e cola. O webhook deve ser validado por token e confirmar o pagamento. Segurança: Usar sessões com expiração de 7 dias. Criptografar senhas. Ocultar credenciais se user.status!="ATIVO". Validar todas as rotas admin com middleware de admin. Front-end: Usar CSS simples no /public. Usar layouts EJS. Dashboard deve ser limpo e responsivo. Funcionalidades finais: Página de login, página dashboard com credenciais, histórico, calendário, link entrar agora, botão suporte, botão PIX, página admin, painel completo de usuários, gerenciamento de credenciais mensais, controle de pagamentos. Entregue todo o projeto funcional com todos os arquivos necessários, incluindo package.json, server.js e instruções de uso.
