CAUSA 1 — Existe um “service fake” cadastrado no banco

Provavelmente existe uma linha na tabela Services com:

id: algo como “servico-teste”
name: "Serviço"


Ou até mesmo uma linha vazia criada automaticamente.

✔ Como confirmar

Roda no console SQL (Neon):

SELECT id, name, isActive FROM "Services";


Se aparecer algo assim:

id	name
servico-teste	Serviço

→ APAGA:

DELETE FROM "Services" WHERE name = 'Serviço';

🧩 CAUSA 2 — O backend está enviando um "serviceId" que não existe

Isso pode estar vindo da tabela UserServices.

Acontece quando alguma assinatura foi criada com:

serviceId = "servico-teste"


Ou qualquer ID que não existe na tabela Services.

✔ Como confirmar
SELECT * FROM "UserServices" WHERE "serviceId" NOT IN (SELECT id FROM "Services");


Se aparecer:

userId	serviceId
...	servico-teste

→ Apaga:

DELETE FROM "UserServices" WHERE "serviceId" = 'servico-teste';

🧩 CAUSA 3 — O frontend está renderizando um card antes da lista real

Isso geralmente acontece quando a UI faz algo assim:

{services.map(service => (
   <ServiceCard ... />
))}


Mas services chega assim:

[
  {},                    <- objeto vazio antes dos reais
  { name: "Vectorizer" },
  { name: "RemoveBG" }
]


Ou seja, o primeiro elemento está vazio → vira "Serviço", porque você provavelmente usa fallback:

{service.name || "Serviço"}

✔ Como corrigir

Filtrar itens inválidos antes de renderizar:

const validServices = services.filter(s => s?.id && s?.name);

validServices.map(service => ...)


OU:

services
  .filter(s => s && s.id && s.name)
  .map(...)

🛠️ A CORREÇÃO REAL PROVÁVEL NO SEU CASO

Pelo visual do card “Serviço”, ele tem:

ícone padrão do Lucide

nome padrão “Serviço”

status ATIVO (vindo do UserServices)

Isso significa:

👉 EXISTE UM REGISTRO EM UserServices QUE NÃO TEM CORRESPONDÊNCIA EM Services.

Exemplo real:

UserServices:
id: 382
userId: X
serviceId: "servico-teste"
status: ATIVO


Mas “servico-teste” não existe na tabela Services.

Então o frontend não consegue pegar o nome do serviço → usa fallback → mostra “Serviço”.

💥 Isso cria esse card fantasma que está aparecendo na sua foto.

🧹 Correção DEFINITIVA

Execute no DB:

1️⃣ Ver quais serviços inválidos existem
SELECT us.*
FROM "UserServices" us
LEFT JOIN "Services" s ON s.id = us."serviceId"
WHERE s.id IS NULL;

2️⃣ Apagar esses registros inúteis
DELETE FROM "UserServices" 
WHERE "serviceId" NOT IN (SELECT id FROM "Services");

3️⃣ Criar UNIQUE pra nunca mais acontecer:
export const userServices = pgTable("UserServices", {
   ...
}, (table) => ({
   uniqueUserService: unique().on(table.userId, table.serviceId),
}));
